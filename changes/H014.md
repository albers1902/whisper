# H014: .htaccess kun med direktiver, serveren tillader (F007 kunne ikke udrulles)
Type: fejl
Hvad: F007's blok i `homedir/public_html/.htaccess` (`AddType font/woff2` og `Header set Cache-Control` for woff2) er fjernet. Filen er igen som før F007, med kun `RewriteEngine`, `RewriteRule` og `RewriteCond`. En ny test (`test_H014-AK1_htaccess_whitelist.php`) afviser alle andre direktiver og `<...>`-blokke. F007-AK9 kræver ikke længere `AddType` i `.htaccess`.
Hvorfor: DEV's `AllowOverride` tillader ikke FileInfo. Apache svarede 500 på alt, også `/health` ("AddType not allowed here"), så deploy af F007 (4f61ac1) rullede tilbage til 5459740. `php -S` ignorerer `.htaccess`, og derfor blev det ikke fanget lokalt.
Cache-headere og MIME-type for fonte kræver serverkonfiguration (sysadmin), hvis det ønskes senere. De kan ikke ligge i `.htaccess`. Uden dem sender Apache woff2 med standard-MIME (`mime.types`) og standard-cache, og browsere viser fontene uændret.
