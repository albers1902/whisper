# F004a: Read-only Adversus-probe
Type: feature
Hvad: `cron/adversus-probe.php` (kun CLI) måler Adversus' API med en API-bruger (HTTP Basic auth): auth, felter og sideinddeling for /calls, /recordings, /sessions, /campaigns og /leads, optællinger over højst 5 sider, og for ét opkald optagelsens værtskæde, Content-Type og størrelse (filen slettes straks). `--call=<id>` gør det samme for ét opkald. Viser kun feltnavne, tal, værter og dokumenterede enum-værdier.
Hvorfor: F004 (hentning af Adversus-opkald) skal bygges på målte data, ikke antagelser (F002/H002-erfaringen).
Flag: ingen
Migrationer: ingen
Rollback: revert-H
Kunde: Ingen synlig ændring; et internt måleværktøj til den kommende Adversus-integration.
