# H003: låste Python-afhængigheder til whisper-setup
Type: fejl
Hvad: `cron/whisper-setup.sh` installerer nu motoren fra låsefilen `cron/whisper-requirements.txt` med præcise versioner og sha256-hashes (`pip install --require-hashes --only-binary :all: --no-deps`) for Python 3.12 på Linux x86_64: faster-whisper 1.2.1, huggingface-hub 0.36.2, av 18.1.0, ctranslate2 4.8.4 og deres afhængigheder. Et venv med andre pakker eller en anden Python bygges forfra. Scriptet laver et import-tjek, før modellen hentes. Modellens Hugging Face-revision er låst pr. model og tjekkes før download. Til sidst transcriberes ét sekunds stilhed gennem hele kæden, før markøren `ready-<model>` skrives.
Hvorfor: På DEV låste scriptet kun `faster-whisper==1.1.1`, så pip valgte huggingface_hub 2.x uden requests, og importen fejlede (`ModuleNotFoundError: No module named 'requests'`). Lukker den del af DECISIONS #15 (F002-S6), der handler om hash-låsning.
