# H010: BatchedInferencePipeline som målbar config-tilstand
Type: fejl
Hvad: `[whisper] engine_mode = sequential | batched` (standard sequential = uændret) og `batched_size = 1–32` (standard 4). Med batched bruger `transcribe.py` faster-whisper 1.2.1's `BatchedInferencePipeline` (VAD altid on, `without_timestamps=False`, samme JSON). Loglinjen pr. opkald slutter med `mode batched|sequential`.
Hvorfor: Transcription på DEV har RTF 0,6–1,5. Ejeren vil måle, om batched er hurtigere på CPU, og beholde den hurtigste.
Flag: ingen
Migrationer: ingen
Rollback: `engine_mode = sequential` (eller fjern linjen) i config.ini, ellers revert-H
Kunde: Ingen ændring for kunder; det er en intern måling af transcriptionens hastighed.
Support: ingen
