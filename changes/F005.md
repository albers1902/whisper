# F005: Nyt UI (redesign)
Type: feature
Hvad: Nyt, roligt og tilgængeligt UI (WCAG 2.2 AA) i hele appen: header med aktiv markering, skip-link og brugermenu; opkaldslisten med søgning først, chips for aktive filtre, klikbare rækker, søgeuddrag med fremhævning, "Viser a–b af N" og pager; detaljesiden med afspiller og transcript side om side, klikbare tidsstempler, fremhævede søgeord og tydelige tilstande; listens filtre bevares til detaljen og tilbage; kopiér-knapper på engangskode, MCP-nøgle, MCP-konfiguration og transcript; lyst og mørkt tema. Ny `assets/app.js` (progressiv forbedring) og ny `assets/app.css`; det gamle UI bruger `assets/legacy.css`.
Hvorfor: Kundeservice skal kunne søge, lytte og læse uden at miste konteksten, og det gamle UI havde kontrast-, fokus- og navigationsfejl.
Flag: F005_ui (dev=on, test=off, stable=off)
Migrationer: ingen
Rollback: stable = off
Kunde: Whisper har fået et nyt udseende, hvor du kan søge, lytte og læse side om side, klikke på et tidsstempel for at høre stedet og komme tilbage til den samme søgning.
Support: Alle skærme har nyt udseende. Søgeord fremhæves, "← Tilbage til opkald" husker filtrene, og tekniske fejlbeskeder ses nu kun af administratorer (brugere får en forklaring). Med flaget slukket vises det gamle UI uændret.
