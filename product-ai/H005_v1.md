# Feature ID
H005

# Version
v1

# Status
READY_FOR_IMPLEMENTATION

# Goal
Transcription bliver markant hurtigere på DEV, og loggen viser hvor hurtig den er, så effekten kan måles.

# Baggrund (målt på DEV 2026-11-12)
- 120 opkald er transcriberet på ca. 16 timer. Det giver ca. 7–8 i timen, eller ca. 8 minutter pr. opkald.
- Der er ca. 1100 opkald tilbage, så bagloggen tager næsten en uge.
- Maskinen har 6 kerner (`nproc`), 11 GiB RAM (6 GiB tilgængelig) og en load på ca. 3,3.
- `cron/transcribe.py` kalder `WhisperModel(model, device="cpu", compute_type="int8")` og
  `transcribe(audio, language="da")` med faster-whispers standarder: `cpu_threads=4`, `beam_size=5` og ingen VAD.
- Jobbet kører under `nice -n 19` og `ionice -c3` (DECISIONS #3).

# Requirements
- `transcribe.py` får argumenterne `--threads N`, `--beam N` og `--vad 0|1`, som valideres: threads 1–32, beam 1–10.
  De sendes videre som `WhisperModel(cpu_threads=N)` og `transcribe(beam_size=N, vad_filter=bool)`. Engineeren
  verificerer navnene på parametrene og VAD's afhængighed (onnxruntime, som allerede er i låsefilen fra H003) i
  faster-whisper 1.2.1's kilde og angiver kilden.
- Config `[whisper]` får valgfri nøgler:
  - `threads`, med standard antal kerner minus 1, mindst 1. PHP finder antal kerner uden shell, fx `/proc/cpuinfo`
    eller `nproc` via argv;
  - `beam_size`, med standard 1;
  - `vad`, med standard `on`.
  Ugyldige værdier giver standarden og én advarsel i loggen.
- `ProcessEngine` sender værdierne som argv-elementer. Der bruges ingen shell, og intet kommer fra brugeren.
  `nice` og `ionice` er uændrede.
- Loglinjen for et færdigt opkald udvides med opkaldets varighed, transcriptionens varighed og forholdet mellem dem
  (RTF):
  `opkald 120: færdig (lyd 4:12, tid 1:05, RTF 0,26, threads 5, beam 1, vad on)`.
- `transcripts`-tabellen ændres ikke. `model` gemmes som i dag.
- Timeout-reglen (max(2 t, 4 × varighed)) er uændret.

# Acceptkriterier
- AK1: Uden nye nøgler i config kaldes motoren med `--threads <kerner-1>`, `--beam 1` og `--vad 1`. Testen bruger en
  falsk python, som i H003/F002 AK4, og læser argv.
- AK2: Config-værdierne overholdes, og ugyldige værdier (fx `threads = 0`, `beam_size = 99`, `vad = måske`) giver
  standarden og én advarsel.
- AK3: Loglinjen indeholder lyd, tid, RTF og indstillingerne i formatet ovenfor.
- AK4: `transcribe.py` afviser ugyldige `--threads`, `--beam` og `--vad` med exit ≠ 0. Testen læser scriptet, fordi
  Python ikke køres i CI, eller kører det med `--help`, hvis Python findes.

# Out of scope
Andre modeller, GPU og flere samtidige jobs. Det kan komme senere, når RTF er målt.

# Feature flag
Ingen. Det er en ydelsesrettelse bag F002's flag.

# Rollback
Revert-H, eller i config `beam_size = 5`, `vad = off` og `threads = 4` for den gamle adfærd.
