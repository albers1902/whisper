# Goal
`whisper-setup.sh` installerer en låst, fungerende kombination af Python-pakker, så motoren kan installeres på DEV
og giver samme resultat hver gang.

# Baggrund
`bash ~/cron/whisper-setup.sh` på DEV (2026-11-11, Python 3.12) gav:
```
✔ faster-whisper 1.1.1 i var/whisper/venv
...
  File ".../faster_whisper/utils.py", line 8, in <module>
    import requests
ModuleNotFoundError: No module named 'requests'
```
Scriptet låser kun `faster-whisper==1.1.1`, og pip vælger derfor nyeste version af de transitive pakker. Nyere
`huggingface_hub` (1.x) bruger ikke længere `requests`, men faster-whisper 1.1.1 importerer det direkte. Det svarer til
accepteret risiko F002-S6 (DECISIONS #15).

# Requirements
- En låsefil `homedir/cron/whisper-requirements.txt` med præcise versioner (`==`) af faster-whisper og alle
  transitive afhængigheder til Python 3.12 på Linux x86_64, gerne med `--hash` (`--require-hashes`). Engineeren
  vælger versionerne ud fra PyPI's metadata:
  - en kombination, der importerer uden fejl, også med `requests`, hvis faster-whisper kræver det;
  - som understøtter modelnavnet `turbo` (large-v3-turbo);
  - helst nyeste stabile faster-whisper, hvis den løser problemet uden at ændre `transcribe.py`'s brug.
  Engineeren citerer kilder (PyPI og faster-whisper's README/CHANGELOG).
- `whisper-setup.sh` installerer med `pip install --require-hashes -r cron/whisper-requirements.txt` (eller uden
  hashes, hvis det ikke er praktisk, og begrundelsen skrives i rapporten). Scriptet laver først et import-tjek, så
  modelhentningen ikke starter med en halv installation.
- Et eksisterende venv med forkerte versioner bringes på plads, når scriptet køres igen. Scriptet kan stadig køres igen
  uden skade, og markøren `ready-<model>` skrives kun til sidst (uændret).
- Modelrevisionen låses, hvis faster-whisper/huggingface_hub tillader det uden større ændringer. Ellers forklares
  det i rapporten.

# Acceptkriterier
- AK1: Låsefilen findes, og alle linjer har `==`. Hvis der bruges hashes, har alle linjer `--hash=sha256:`. En CI-test
  læser filen og tjekker formatet.
- AK2: `whisper-setup.sh` bruger låsefilen og ikke en løs `pip install faster-whisper==…` alene. En test læser
  scriptet.
- AK3: Låsefilen indeholder `requests` eller en version af `huggingface_hub`, som faster-whisper-versionen er
  kompatibel med. Engineeren dokumenterer, hvorfor kombinationen virker.
